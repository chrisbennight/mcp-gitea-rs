# Documentation

Start with the [Docker Quickstart](../README.md#run-with-docker) to connect an
MCP client to Gitea. Then choose the guide for your task.

| Task | Guide |
| --- | --- |
| Set credentials, rotate the bearer, or configure a proxy | [Configuration](configuration.md) |
| Choose a client and retrieve a large result | [MCP client compatibility](clients.md) |
| Find an operation and understand its result | [Operation and response reference](operations.md) |
| Diagnose startup or authentication | [Troubleshooting](troubleshooting.md) |
| Understand the account and network boundary | [Security](../SECURITY.md) |
| Build, test, or contribute a change | [Contributing](../CONTRIBUTING.md) |
| Understand the implementation | [Architectural decisions](../DECISIONS.md) |
| Inspect CI and container publication | [Automation](automation.md) and [releases](releases.md) |
| Update presentation or documentation | [Visual identity](branding/README.md) and [writing guide](writing.md) |

The [preparation plan](../PLAN.md) tracks remaining work before public release.
The [OpenAPI provenance](../openapi/SOURCE.md) records the pinned upstream input.
